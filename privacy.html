Datenschutzerklärung

Die Anwendung „Wohlstandsvisionen“ ist ein privates Werkzeug, mit dem der Betreiber eigene, selbst erstellte Kurzvideos auf seine eigenen YouTube-Kanäle hochlädt.

Welche Daten werden genutzt?

Die Anwendung nutzt über die YouTube Data API ausschließlich die Berechtigung, Videos auf die Kanäle des Betreibers hochzuladen und die Kanalnamen dieser Kanäle abzufragen. Es werden keine Daten anderer Personen erhoben, gespeichert oder weitergegeben. Die Zugangsdaten (OAuth-Token) werden nur privat beim Betreiber gespeichert.

Google API Services

Die Nutzung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Privacy Policy

“Wohlstandsvisionen” is a private tool the operator uses to upload their own short videos to their own YouTube channels.

Through the YouTube Data API it only uses permission to upload videos to the operator's channels and to read those channels' names. No data about other people is collected, stored or shared. Access tokens are stored privately by the operator only.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
